# Database engine brand icons

The six monochrome SVG paths are vendored from Simple Icons version 16.38.1 (https://github.com/simple-icons/simple-icons), retrieved from the npm package. See LICENSE.md for the upstream CC0 dedication. Brand names and trademarks remain the property of their respective owners; their use identifies connection types, not endorsement.

The shared DatabaseIcon component supplies consistent sizes and colored backgrounds. The SVG shapes are unmodified and load locally, with no external requests or runtime icon dependency. These icons are distinct from the user-approved DB EX application artwork.
