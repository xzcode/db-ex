# DB EX v0.5.4 (Preview)

- New database-first connection chooser and engine-specific general settings.
- MySQL: default root username and port 3306. MongoDB: fields or independent MongoDB URI entry, topology and authentication choices. Redis: Standalone, Cluster and Sentinel forms.
- General / TLS / SSH / Proxy / Advanced tabs. Native file selectors for certificates and SSH private keys. Password visibility toggles apply only to newly entered values; saved secrets remain redacted.
- Test or open a temporary connection before naming it. Save and save-and-connect remain separate.
- Built-in encrypted storage, portable connection backups, OS-language default and 14-language localization remain intact.
- macOS Apple Silicon, Windows x64 and Linux x64 native preview installers.
