# DB EX M6 handoff — 2026-11-25

## Scope and decisions
- Integrate the object-inspector and SQLite/preferences work as a single candidate; the old PR #15 failed its typecheck, and PR #16 contains the fix. Do not publish or merge the failing upstream revision separately.
- SQLite native calls run in a terminable process. Electron uses its utility process, and the standalone Node regression uses a fork. Packaged smoke exercises actual SQLite IPC before replacing other fixtures. The child bundle is explicitly unpacked.
- Restore saved connection/object/editor locations and encrypted query/record drafts. Record draft recovery requires explicit write access; it never submits a mutation automatically. Record editing remains bounded; periodic recovery is not a forced-exit guarantee.
- Native direct MySQL/MongoDB tools ignore login path overrides for MySQL and clean up credentials after child exit. SQLite incompatible full exports are rejected rather than exporting truncated previews.
