# DB EX v0.5.3 (Preview)

- 14 UI languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, German, French, Spanish, Portuguese, Russian, Italian, Arabic, Hindi and Indonesian. Follow the operating system's preferred language by default; unsupported languages fall back to English. Arabic mirrors the interface.
- Live toolbar language selection, saved locally; no account or restart required.
- Localized connection manager, connection settings, MySQL/MongoDB/Redis workbenches, query history and favorites, application-owned dialogs, and common diagnostics. Less-common cataloged messages may fall back to English.
- Existing connection configurations, credentials, SQL, database values and identifiers are unchanged. Unrecognized driver diagnostics are preserved.
- Retains v0.5.2 built-in encryption and portable connection backups.
- macOS Apple Silicon ad-hoc signed preview, Windows x64 and Linux x64 native installers.
