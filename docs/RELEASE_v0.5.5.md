# DB EX v0.5.5 (Preview)

- Per-value BSON type indicators and colors in MongoDB result grids, including mixed numeric widths and missing versus null.
- Read-only, expandable document tree with BSON metadata and a raw EJSON tab. The existing EJSON editor, permissions and exports are unchanged.
- Independently configure each BSON type color or clear its color; toggle grid labels and coloring, and restore defaults. Preferences persist locally.
- Shared color palette expanded to 36 presets, native custom color selection, HEX entry and 12 recent custom colors.
- Existing connection groups, connection colors, encrypted backups and 14 UI languages remain supported.
- Preview metadata and document tree have bounded budgets. Unsupported/unpreserved driver types are not guessed.
- Native macOS ARM64, Windows x64 and Linux x64 preview packages.
