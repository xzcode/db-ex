# DB EX 核心产品需求（PRD v0.1）

## 定位

面向个人开发者的本地优先跨平台数据库管理工具：一个客户端管理 MySQL、MongoDB、Redis，以强连接能力、明确安全边界、低学习成本为核心竞争点。不要求注册账号，也不依赖远程后端。

## 首期用户任务

1. 将多个环境的连接分组保存、检索、连接与断开。
2. 通过 TCP / SSH 跳板机 / TLS 访问私有网络数据库，快速识别连接错误。
3. 浏览数据库、表/集合和 Redis Key，有限量查看记录详情。
4. 在多工作标签中执行安全的查询和数据维护（M2-M4）。
5. 使用连接配置导入/导出和跨平台发行（M5 完善，敏感字段不能明文导出）。

## 功能边界

| 功能 | 里程碑 | 首版完成标准 |
|---|---|---|
| 数据库连接 | M1 | MySQL/MongoDB/Redis 单节点直连，连接状态可观察 |
| SSH 隧道 | M1 | 密码/私钥/Agent，可验主机密钥，回环端口转发 |
| TLS | M1 | 支持 CA、客户端证书和密钥路径，默认验证证书 |
| 凭据存储 | M1 | 系统加密存储、禁止明文降级 |
| 数据导航 | M1 | 基础树形资源浏览与限制数量的数据预览 |
| MySQL | M2 | SQL 编辑、结果分页、编辑与事务 |
| MongoDB | M3 | BSON 编辑、过滤、聚合、索引 |
| Redis | M4 | Key/TTL/数据类型编辑与命令台 |
| 高级网络 | M5 | SOCKS5、HTTP CONNECT、多跳 SSH、集群兼容 |
| 发行 | M5 | macOS/Windows/Linux 打包与签名流程 |

## 非目标

首版不开发数据库模型设计、商业授权管理、AI 生成 SQL、云端同步、自动备份调度、团队协作、实时数据库监控、DBA 性能诊断。后续可作为插件或独立里程碑。

## 安全与体验原则

- 生产连接默认只读，任何危险操作需要额外明确确认；数据库权限始终是最终保护。
- 用户可以快速检测连接失败原因，绝不以自动禁用 TLS 校验来消除错误。
- 三库使用统一工作台，但 MongoDB BSON 类型和 Redis 原生类型不可被 SQL 抽象抹掉。
- 所有大规模数据操作有分页、最大返回量与取消机制。
- 长方形按钮、专业桌面工具风格、可访问的键盘操作。

## 验收用例

- MySQL 密码连接，MongoDB URI 连接，Redis ACL 连接均能正确显示成功或详细错误。
- 通过 SSH 隧道连接一个未暴露公网端口的单节点 MySQL；未知 SSH host key 必须拒绝连接直到人工确认。
- 使用 TLS CA 校验，证书不可信时提示错误且不自动放行。
- 100 万行表、10 万 Key 环境下浏览器不尝试一次性下载全部记录。
- 退出进程后，配置中不出现明文密码。无安全存储能力时拒绝保存。
