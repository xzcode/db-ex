# 连接参数与高级网络

## 建立连接

新建连接先选择 MySQL、MongoDB 或 Redis，再进入对应的常规设置窗口；也可从入口直接使用 MongoDB URI。常规页只展示当前数据库需要的主机、端口、拓扑及认证字段；SSL/TLS、SSH、代理、高级设置独立分栏。连接名称用于保存配置，测试及临时连接可在未填写名称时执行。证书与 SSH 私钥路径可通过本机文件选择器填写。可先“测试连接”，再临时连接或保存。每次建立的会话默认只读；需要修改数据时解锁当前会话，再逐次确认写操作。

| 参数 | 含义 |
|---|---|
| `kind` | `mysql` / `mongodb` / `redis` |
| `host`, `port` | 数据库逻辑地址；默认端口分别为 3306、27017、6379 |
| `username`, `password` | 数据库账号；Redis username 对应 ACL 用户 |
| `database` / `authSource` | 默认数据库 / MongoDB 认证数据库 |
| `redisDb` | Redis 逻辑库，0–1023 范围内还必须被服务端支持；Cluster 固定为 0 |
| `connectTimeoutMs` | 单阶段连接超时，默认 12000 ms，可设 1000–60000 ms；多节点过程可能经历多个阶段 |
| `nodes` | MongoDB / Redis 的种子节点，最多 20 个 |

保存配置使用程序内置 AES-256-GCM 密钥自动加密，保存和读取不要求主密码或系统钥匙串。旧版系统加密数据会尝试一次性迁移；若无法访问旧密钥，保留旧条目并可新建连接。编辑已保存配置不会把保存的密码或完整 MongoDB URI 返还界面；空白表示保留同一端点的已有凭据，清除必须显式指定。

## 传输路径

支持直接 TCP、SOCKS5 和 HTTP CONNECT，可与 SSH 链组合。组合路径是：本机 → 可选代理 → 第一个 SSH 节点 → 后续 SSH 节点 → 数据库。未启用 SSH 时，代理直接连接数据库及其发现节点。

代理支持无认证或用户名/密码认证。HTTP CONNECT 使用 HTTP/1.x CONNECT 和可选 Basic 认证；本轮不提供到 HTTP 代理本身的 HTTPS 包装或 NTLM/Kerberos 协商。数据库 TLS 是独立配置。SOCKS5 使用 CONNECT，不开放 UDP ASSOCIATE 或 BIND。

## SSH 多跳

最终 SSH 节点可附加最多三个有序前置跳板，总计最多四级 SSH。各级分别配置地址、端口、用户名及以下认证之一：

- 密码。
- 本地 OpenSSH 私钥路径及可选私钥口令；私钥内容由主进程读取。
- 本机 SSH Agent，使用指定 Agent Socket 或 `SSH_AUTH_SOCK`。不将 Agent 转发到远端。

每一级都需要独立核对 `hostFingerprint`。格式是主机公钥 SHA-256 的 **64 位十六进制摘要**，不同于 OpenSSH 默认显示的 `SHA256:<base64>` 字符串。未知主机错误会显示当前指纹与跳数，必须与管理员或其他可信渠道核对后填写；指纹变更不会被自动接受。

这里使用 SSH `forwardOut` 建立 TCP channel，不执行远程 shell。下一跳必须能从上一跳访问，数据库及集群宣告地址必须能从最终 SSH 节点访问。任一级连接断开会关闭整个传输作用域和所有下游 socket。

### 导入 SSH config

支持明确 Host 别名及匹配这些别名的通配配置，遵循先得到的值优先的子集行为。支持 HostName、User、Port、首个 IdentityFile、IdentityAgent、ProxyJump，以及 `~/` 和有限的 `%` 路径变量。可识别多个 ProxyJump，并在展开后检查环和层数。

不执行 ProxyCommand、Match exec、LocalCommand、RemoteCommand；不读取 Include 目标文件。含不支持内容的条目会跳过或给出警告，不能把导入结果当成完整 OpenSSH 配置等价物。导入不会自动信任主机密钥，仍须填写各级指纹。

## TLS

启用后支持 CA、客户端证书和私钥路径；客户端证书与私钥必须成对配置，可使用分离 PEM。证书文件须为普通文件且单个不超过 2 MiB。本轮要求 TLS 1.2 或更高，始终校验证书链和主机名，不提供“不安全连接”开关。

传输层保留数据库真实地址，因此通过代理/SSH 时仍按逻辑节点名称验证证书。`tls.servername` 是显式的证书名称覆盖，仅在证书与部署拓扑确实需要时使用；集群节点证书身份不同的部署不应给所有节点套用同一错误名称。证书不匹配应修正 CA、名称或部署，不能绕过校验。

## MongoDB

可使用字段配置或 `mongodb://` / `mongodb+srv://` URI。完整 URI 加密保存，连接列表及编辑回读均不返回其内容。URI 和字段配置不要混用不同认证信息；使用 URI 时驱动采用 URI 内认证配置。

拓扑模式有 `auto`、`direct`、`discover`：**自动模式下仅填写一个主机（未配置 Replica Set 或 URI）时，默认直连该端点**，不尝试连接服务器向外宣告的其他副本集成员，适合公网端口映射或只暴露单个入口的 SSH；明确填写 Replica Set 名称或多个种子节点时保留驱动自动发现。完整 URI 仍优先采用 URI 内的拓扑选项。需要高可用故障转移时请选“副本集发现”，确保所有成员都可达。旧连接配置中的 `mongoDirect=true` 继续表示强制直连。启用 SSH/代理时，应用建立一个带随机会话认证的 loopback SOCKS5 入口，驱动发现的成员继续经过相同传输路径。发现成员的 DNS 名称与端口必须对最终出口可达；本轮没有任意 NAT 地址映射表。

SRV/TXT 发现由本机 DNS 执行。仅在跳板机内部可解析的 SRV 名称，需要改用显式种子列表或配置本机可用的 DNS；代理不会自动代理 SRV 查询。

URI 禁止 `tlsInsecure`、无效证书/主机名放行、代理覆盖以及绕过表单的证书文件路径。 MongoDB URI 通过 `tls=true` / `ssl=true` 启用 TLS、或 SRV URI 默认启用 TLS 时，DB EX 也会读取 TLS 页面填写的 CA、客户端证书和私钥路径，即使未额外勾选 TLS 开关；仍会强制验证证书链与主机名。TLS 表单启用时拒绝 URI 的 `tls=false` / `ssl=false` 冲突。

副本集选主或瞬时网络故障时，驱动可在操作时间预算内重新选择节点并安全重试明确可重试的读取；总操作仍受 30 秒上限与取消信号约束。写入自动重试保持关闭，不确定的写入结果需要用户核对后重新发起。此机制不保证所有游标阶段都能恢复，也不保证跨次读取构成一致快照。

### MongoDB 连接失败时怎么判断

先在连接弹窗点击「测试连接」，按返回的错误类别检查：

- `MONGO_AUTH_FAILED`：用户名、密码或 `authSource` 错误；应用选择 URI 时，上方独立认证字段不参与认证。
- `MONGO_CONNECTION_REFUSED` / `MONGO_DNS_FAILED`：检查主机、端口、监听范围和 DNS；远程服务器不应误填本机的 `127.0.0.1`，除非通过 SSH 隧道访问远端 loopback。
- `MONGO_TLS_FAILED`：核对 TLS 开关、CA 和证书主机名，不应为绕过报错而关闭校验。
- `MONGO_TOPOLOGY_FAILED`：核对副本集名称及各成员地址；仅用于单节点管理时可启用直连。
- `MONGO_TIMEOUT` / `MONGO_SERVER_SELECTION_FAILED`：排查网络、SSH/代理、防火墙及节点可达性。
- `MONGO_URI_INVALID`：核对 URI 语法，账号密码含特殊字符时必须百分号编码。
- `MONGO_VERSION_UNSUPPORTED`：核对服务端版本；当前 MongoDB Node 驱动 6.x 要求 MongoDB 4.2 或更新版本，Navicat 可能使用不同驱动。

这些提示不会显示原始驱动异常、凭据或完整 URI。尚未能识别的错误仍显示保守的 `CONNECTION_FAILED`。

连接测试现在会在驱动建立连接后执行一次只读 `ping`，确认实际服务端命令和认证可以成功，而不只是客户端创建成功。MongoDB 的常规页在主机/端口与 URI 两种方式之间切换。URI 模式不显示独立认证与拓扑字段，并使用完整 URI；新输入的 URI 不会继承隐藏的字段设置。旧版保存的 URI 保持原有连接身份，转为主机模式时显式清除旧 URI。种子节点列表非空时优先使用列表，并在列表界面显示实际种子地址。MongoDB 和 Redis 可选择无认证或密码认证；无认证模式会清除已保存的数据库密码。

## Redis

| 模式 | 配置与行为 |
|---|---|
| Standalone | 数据库 host/port、ACL username/password、redisDb；直接或代理/SSH |
| Sentinel | 填写 Sentinel 种子列表和 master 名称；Sentinel 可使用独立账号、密码、TLS 开关；发现的主节点使用数据库凭据和数据库 TLS |
| Cluster | 填写一个或多个种子节点；仅 DB 0；支持节点发现和 MOVED/ASK 路由；每个节点使用相同传输作用域 |

Sentinel 重连会重新向配置的 Sentinel 查询主节点，同时周期检查连接角色；本轮重试次数有限，不能把它视为无限自动恢复。Cluster 保留原始节点名称，避免在本机预先解析成 IP 后破坏远端 DNS 或 TLS 身份验证。集群宣告地址必须从最终网络出口可达。

Key 浏览在 Cluster 中按主节点进行 SCAN，不承诺全局排序或一致快照。跨槽删除逐 Key 路由，因此可能部分完成。连接恢复不自动重放尚未得到响应的写命令；发生超时、断线或切换后，应刷新核对写入结果。

## 配置导入导出

点击连接列表底部“导出连接”可备份全部连接，单条连接的导出按钮可备份当前连接。JSON v2 备份包含内置密钥加密的连接配置、数据库/SSH/代理/Sentinel 密码、私钥口令及 MongoDB URI。无需输入或保管额外密钥。

其他 DB EX 可以直接导入 v2 备份，恢复密码及认证设置；导入新增连接，不覆盖已有记录，也不会自动连接或执行命令。旧 v1 脱敏模板仍可导入，但需重新填写缺失的凭据。最大保存连接数为 200。证书、私钥文件需另行复制并调整路径；内置密钥公开，请勿共享含凭据的备份。

连接备份不携带 SSH 主机信任决策：导出和导入均移除主机指纹，导入后必须重新独立核验。已保存连接的编辑仍保留原有、已经核验的指纹。

## 错误与排查

`SSH_HOST_KEY_UNTRUSTED` / `SSH_HOST_KEY_MISMATCH` 表示指纹待核对或已变化；`PROXY_AUTH_FAILED` 表示代理认证失败；`SSH_FORWARD_FAILED` 表示最终出口无法连接目标或禁用了 TCP 转发。TLS 失败须检查信任链、有效期及名称，不能禁用校验绕过。

`SESSION_BUSY` 表示当前会话已有操作；`TIMEOUT` / `CANCELLED` 后会话会断开；`EDIT_CONFLICT` / `CONFLICT` 表示数据已变化。数据库错误只公开稳定代码和经过脱敏的提示，不回传可能包含凭据或记录内容的原始驱动异常。

### MySQL TLS 的 IP 身份限制

当前 mysql2 在对 IP 建立 TLS 时可能回退校验 socket 地址或localhost。为保证正确的身份校验，DB EX 要求 MySQL TLS 使用证书中的 DNS 名称；数据库目标仍可填写 IP，但需在“证书主机名 / SNI”填写证书覆盖的 DNS 名称。只有 IP SAN 的证书暂不接受，连接会明确拒绝，不会退回关闭校验。MongoDB/Redis 不受此 mysql2 限制。

## 左侧连接管理

在连接上右键或点击行末菜单，可连接、断开、编辑、选择颜色、移动到分组、导出及删除。颜色支持 36 种预设、系统自定义拾色器、HEX 输入、最近 12 个自定义颜色和无颜色。连接行、活动标签页及资源浏览器标题同步使用同一颜色；颜色仅用于连接标记，不改变写入权限。

通过“移动到分组”输入新名称或选择已有分组；可拖动连接至已有分组，或拖至移出分组区域。分组可展开/折叠，折叠偏好保存在本机。分组基于连接配置中的可选名称，最后一个连接移出后不保留空分组。颜色和分组会随加密连接备份一起迁移。外观更新通过专用 IPC 保存元数据，不读取或回传已保存密码。

## MongoDB 类型显示

MongoDB 查询、Aggregation 和索引结果的类型由主进程从实际解码 BSON 值生成，不从字符串或字段名推测。每个可见单元格独立显示类型，区分 Int32、Int64、Double、Decimal128、ObjectId、Date、Timestamp、数组、内嵌文件、Binary、Boolean、Null、缺失字段等。非常用 BSON 值按驱动实际解码的类型标记；驱动未保留或没有元数据的值不猜测具体数值宽度，显示 Number 或 Unknown。

双击 MongoDB 结果行或点击“查看文档”打开只读类型树，也可以切换到完整原始 EJSON。类型树支持展开真实内嵌文档和数组；在预览预算耗尽后不推断未知类型，原始 EJSON 保留。原有编辑按钮、EJSON 写入、导出格式和写入确认不变。

工作区的“BSON 类型配色”中，可分别为每种类型选择颜色、取消颜色、恢复单项或全部默认配置，也可关闭着色和隐藏网格类型标签。偏好保存在当前应用本地，不随数据库连接备份迁移。连接标记色和 BSON 类型配色独立；两者共用 36 个预设色和最近使用的自定义颜色。自定义 HEX 支持 #RRGGBB，也可使用本机拾色器；最近颜色右键可移除。

## 自由分组（v0.5.6）

不再要求选择开发、测试或生产环境；可以使用任意分组名称、连接名称和自定义颜色组织连接。旧版配置及备份中的 `environment` 字段读取时忽略，重新保存或导出时不再写入该字段，不影响其他字段、凭据或已有分组。所有连接默认只读，解锁与每次写入确认仍然生效，并显示目标连接名称和地址。

## MongoDB 数据浏览（v0.5.6）

浏览表格使用 BSON 实际类型元数据及原始 Canonical EJSON 的独立显示格式：ObjectId 显示十六进制 ID，Int32/Int64/Double/Decimal128 显示数值文本，Date 显示 UTC 日期时间，不将长整数和高精度小数转换为 JavaScript 数值。对象、数组、二进制显示内容数量摘要；Null 显示 `(NULL)`，缺失字段显示 `—`，字符串 `NULL` 保持原样。原始字符串中的换行和制表符在紧凑网格中使用可见符号，完整原文仍在原始 EJSON 中。

默认整格按 BSON 类型着色，ObjectId 橙色、Int32 绿色、Int64 紫色；Null 和缺失字段默认不着色。网格类型标签默认隐藏，悬停显示实际类型和显示值，仍可在配色设置中开启标签或自定义颜色。已有自定义覆盖保留。双击记录打开文档树，原始 EJSON、编辑及 JSON/CSV 导出继续使用原来的数据路径。查询条件默认收起，可按需打开；默认每页 200 条，可切换 100/200/500 条。列宽可拖动、键盘调整，双击分隔线恢复自动宽度。

### 文档右键菜单与编辑

在 MongoDB 结果记录或单元格上右键，提供查看文档、编辑文档、新增文档、复制为新文档、删除文档、复制字段值、复制完整 EJSON 文档、设为 NULL、设为空字符串、按此值筛选。复制和筛选不写入数据；复制为新文档删除原 `_id`，字段修改先打开编辑草稿，需显式确认才写入。筛选支持安全的标量字段名，并将选中值的实际 BSON 类型保留在 `$eq` 条件中，Null 额外检查字段存在；已有筛选以 `$and` 合并。投影/聚合结果不能用于替换或删除原文档。

编辑默认使用可读、缩进及高亮的 BSON 构造语法，例如 `ObjectId("507f1f77bcf86cd799439011")`、`Int32("19107")`、`Long("9223372036854775807")`、`Decimal128("1.25")`、`ISODate("2026-01-01T00:00:00.000Z")`。仅解析白名单数据语法，不执行 JavaScript。验证通过主进程 BSON 驱动进行本地语法、类型、大小和 `_id` 校验，不连接数据库；更新前自动验证，再使用原有写入确认和原始完整文档冲突检测。普通整数按 Int32/Int64 范围解析，小数按 Double 解析；需要其他数值类型时显式使用构造语法。少见类型可以保留或切换至原始 EJSON，已知有 EJSON 歧义或元数据不足以安全判定的文档拒绝编辑/复制为新文档，以免改变原始 BSON 类型。

## 对象详情侧栏（v0.5.7）

在工作区顶部打开对象信息、DDL 或类型配色，右侧面板可展开、关闭及手动刷新，切换对象后自动读取新对象。MySQL 使用 information_schema.TABLES/COLUMNS/STATISTICS 和 SHOW CREATE TABLE 获取表/视图信息及原生 DDL，行数为估算。MongoDB 使用 listCollections、collStats 和 listIndexes 获取集合选项、统计及索引，生成只读 mongosh DDL 预览；无法准确复原的特殊索引（例如内部文本索引）会明确提示。统计是服务端返回的快照，权限不足时显示不可用，不伪造数据。Redis 无传统 DDL，选中 Key 可查看类型、TTL、长度、采样内存用量、内部编码及可复制的只读检查命令（JSON 参数数组，不是恢复脚本）。

DDL 面板提供复制和导出文本；不会自动执行。MongoDB、MySQL、Redis 各自保留独立配色方案。MySQL 基于驱动返回的列类型和真实 NULL，MongoDB 基于 BSON 值类型，Redis 基于 Key 类型而非字符串推测；配色统一复用 36 色及自定义 HEX、最近颜色、类型标签开关、默认值恢复。设置本地持久化，现有 BSON 配色继续有效。

### 可视化筛选与分页

MongoDB 与 MySQL 数据页顶部的查询条件按钮展开可视化筛选工具：最多 12 组、50 个条件、32 个排序字段，组间和组内分别支持 AND/OR。MongoDB 允许输入嵌套字段路径并选择实际 BSON 类型，也保留 Filter/Projection/Sort 文本模式；可视化应用会替换当前筛选和投影，文本模式只在明确查询后生效。MySQL 使用字段选择和固定操作符，在主进程生成参数化 SQL；显式 Long/Int32 使用有符号整数转换、Decimal128 使用 MySQL DECIMAL(65,30) 可表示范围，其他参数按数据库类型转换。

数据页底栏提供新增、删除、刷新、取消并断开、首页/上一页/下一页/末页、输入页码回车、100/200/500 每页条数、表格/单记录/文本视图。末页需要按当前已应用筛选统计记录数（最多 1,000,001，保留现有 30 秒超时和最大偏移），不是固定快照；并发变动或未指定排序时分页可能变化。记录编辑保存/取消仍使用编辑窗口的明确审阅流程。Redis SCAN 只提供批次游标导航，重新扫描上一批不保证完全相同结果，不提供虚构的总页数及末页跳转。

筛选器扩充为完整的比较、包含/不包含、开头/结尾及反向匹配、NULL/非 NULL、空/非空、列表/非列表条件。MongoDB 另外支持存在/不存在、BSON 字段类型/非类型及受控自定义字段条件。每条规则可独立启用、禁用、上移/下移，规则之间可选择 AND/OR，AND 优先于 OR；条件组用于明确括号关系。禁用条件不参与查询。MongoDB 空值判断采用原生匹配语义（空字符串、空数组或空文档），与 NULL、缺失字段区分；MySQL 空值表示空字符串长度。BSON 类型匹配沿用 MongoDB $type 查询语义，包括数组元素匹配。MySQL 不展示 MongoDB 专用操作符；复杂 SQL 使用原有 SQL 编辑器。

点击值输入旁的按钮打开带类型选择、搜索与建议值的窗口。建议值仅从当前查询结果页提取最多 100 个去重值，不进行全表 DISTINCT 扫描；相同显示文本的不同 BSON 类型分别列出。列表匹配使用同一类型的 JSON 字符串数组，可勾选建议值，长整数及小数不经不精确 JS 数字转换。自定义 MongoDB 字段条件仍须通过主进程读操作策略，不执行 JavaScript。筛选修改只在应用按钮后查询。

MongoDB 的筛选值类型菜单仅展示文本、数字、日期时间、对象 ID、自定义。数字手动输入时按数值范围选择 Int32/Long，普通小数使用 Double，高精度小数使用 Decimal128（由 BSON 驱动继续校验可表示范围）；单值建议保留实际 BSON 类型，列表首次选择建议值后保留其类型。日期时间输入 UTC ISO 时间，自定义使用非执行 BSON 构造语法（例如 Long("7")、Decimal128("1.25")、true 或文档值），而不是执行任意 JavaScript。此简化只影响 MongoDB 的筛选值控件，不改变类型配色、编辑器或 MySQL 类型列表。
